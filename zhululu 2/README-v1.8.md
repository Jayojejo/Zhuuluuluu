# ZHULULU v1.8 — Psychedelic Arcade

Mobile-first update based on v1.7. Direct game selection without a lobby. Added fictional JOINT ROLL timing minigame (three targets, points and feedback), clearer instructions and a start screen for each minigame, larger mobile buttons, improved menu visuals, refreshed offline cache. The seven previous arcade minigames and Open World remain. Multiplayer rooms apply to Open World; arcade minigames are local single-player.

Deploy: upload the **contents** of the `zhululu` folder to the root of the GitHub repo used by Render. Render Web Service: `npm install`, `npm start`. Reload after deployment.

This is an enhanced 2D prototype, not a fully polished commercial game. No end-to-end mobile browser test or production multiplayer test has been performed.
